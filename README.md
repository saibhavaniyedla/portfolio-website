# Sai Bhavani Yedla Portfolio

This is my personal portfolio website designed to showcase my skills, projects, certifications, resume, and contact information in a clean and creative way. 
The website is built using HTML, CSS, and JavaScript with a modern purple, blue, and pink theme.
It is created as a beginner-friendly and responsive portfolio that represents my learning journey in web development, AI/ML, and software projects.
The portfolio includes different sections such as About Me, Skills, Projects, Certifications, Experience, Education, Resume, and Contact. 
It also includes a separate feedback page where visitors can contact me or share suggestions through a contact form.

Visit my website - https://sai-bhavani-portfolio.onrender.com

## About the Portfolio

This portfolio website is created to present my academic background, technical skills, and project work in one place. It helps recruiters, mentors, classmates, and collaborators understand my learning progress and the technologies I am exploring.
The design focuses on a modern look with animated elements, hover effects, gradient colors, and a clean layout. The SBY logo is designed inside a single bubble, and the menu has a dark rounded navigation box. The hero section includes a rolling orbit animation in the background to make the website more attractive and unique.

## Contact Form

The feedback form is connected using FormSubmit. When a visitor submits the form, the message is sent to the registered email address.

The form includes:

* Name
* Email
* Message type
* Message

To test the contact form properly, open the project using Live Server or deploy it online. The form may not work correctly if opened directly using a local file path.

## How to Run Locally

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Make sure all files are in the same folder.
4. Open `index.html` using Live Server.
5. Visit the portfolio in the browser.
